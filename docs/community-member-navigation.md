# Community Member Navigation

## Menu

The member app shell presents these destinations in order:

1. **Home** opens the existing dashboard.
2. **Learning** opens the Learning Hub.
3. **Portfolio** opens the existing Project Pipeline.
4. **Forum** opens the existing community discussion experience.
5. **Office Hours & Events** opens the event experience.
6. **Submit Your Project** opens the project-intake form.

Contractors is not shown as a menu item. Messaging is not a standalone menu item; members can open it from the Forum header. Read-only guests do not see the Submit Your Project destination or the Messaging shortcut.

## Dashboard

The dashboard restores the branded community hero artwork, followed by **Not sure where to start?** and five linked prompts in menu order: Learning, Portfolio, Forum, Office Hours & Events, and Submit Your Project. The old metrics and generic action-card sections remain omitted from this member dashboard view.

The dashboard contact section links to [hello@tribes.capital](mailto:hello@tribes.capital).

## Forum Presentation

Forum uses a spacious introduction on the neutral page background, with a deep-purple topic panel and purple, charcoal, and white accents from the portal palette. Number labels in the topic panel are plain text with no colored tiles. Discussion filters are grouped under a clear topic label, posts have more breathing room, and the side panels distinguish popular topics from active members. The hero and action layout stack on narrow screens; the homepage artwork uses a contained image treatment on mobile to preserve its headline.

## Portfolio Access

Authenticated community members can read the Project Pipeline. The existing project service limits list and detail results to published projects and projects the user created or belongs to as a team member. Project creation and mutations remain investor/admin-only; the member-facing pipeline displays a disabled **Create Project** button.

Read-only guest access to project endpoints remains blocked by the account-type guard.

## Project Intake

The intake form collects a project name, type, location, capacity, contact email, and overview. Continuing opens a prefilled email addressed to `hello@tribes.capital`; the user reviews and sends it through their email app. The form does not persist a submission in the application or create a pipeline record.
